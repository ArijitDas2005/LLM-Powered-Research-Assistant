📡 API Endpoints

GET Health Check
/api/health/
Check API status and available endpoints
POST User Login
/api/users/login/
Get JWT token with credentials
POST Register User
/api/users/register/
Create new user account
GET User Profile
/api/users/me/
Get authenticated user details
POST Submit Research Job
/api/research/jobs/
Create async research job for company
GET Research Jobs
/api/research/jobs/{id}/

GET Research Reports
/api/reports/

GET Semantic Search
/api/search/?query=
Search reports with semantic similarity
GET Usage Analytics
/api/usage/
View API usage and token consumption
GET Admin Panel
/admin/
Django admin interface

🚀 Quick Start

1. Register a new user

POST /api/users/register/
{ "username": "user123", "email": "user@example.com", "password": "secure123" }

2. Login to get JWT token

POST /api/users/login/
{ "username": "user123", "password": "secure123" }

3. Submit research job

POST /api/research/jobs/
{ "company_name": "Apple Inc" }
Requires: Authorization: Bearer {token}

4. Check job status

GET /api/research/jobs/{job_id}/
Requires: Authorization: Bearer {token}
